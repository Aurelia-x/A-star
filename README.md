# 启发式搜索算法演示系统

本系统实现了一套从"盲目搜索"到"启发式搜索"再到"时空权衡搜索"的完整算法演进链路，支持 8 数码、15 数码及迷宫寻路三类问题的交互式求解与可视化回放。

### 核心模块说明

| 模块 | 职责 |
|------|------|
| `base_classes.py` | 定义 `Problem` 抽象基类和 `Node` 数据结构，为算法实现提供统一接口 |
| `domains.py` | 实现 `PuzzleProblem`（数码问题）和 `MazeProblem`（迷宫问题），包含可解性判断与随机生成 |
| `algorithms.py` | 实现全部五种搜索算法，复用统一的 `Problem` / `Node` 接口 |
| `heuristics.py` | 实现三种启发函数：错位棋子数、曼哈顿距离、线性冲突 |
| `benchmark.py` | 批量运行多组预设测试用例，输出时间、扩展节点数、内存峰值等五项指标 |
| `main.py` | 终端交互式前端，支持单屏刷新菜单、分层返回、问题编辑、算法选择与结果回放 |

## 支持的问题类型

### 8 数码问题

- 在 3×3 的棋盘上，通过滑动空格将打乱的数码排列为目标状态
- 预设三种难度：简单、中等、困难

### 15 数码问题

- 在 4×4 的棋盘上作业，状态空间约 $10^{13}$
- 预设三种难度：简单、中等、困难

### 迷宫寻路问题

- 支持预设 8×8 迷宫、手动编辑迷宫、随机生成迷宫
- 支持**变长边权**：普通空地代价为 1，泥潭地块代价 ≥ 2
- 迷宫尺寸、障碍率、最大权重、随机种子均可自定义

## 支持的算法

| 算法 | 类型 | 是否保证最优解 | 说明 |
|------|------|:---:|------|
| **BFS** | 图搜索（盲目） | 是（仅边权相等） | 基准算法，$O(b^d)$ 时空复杂度 |
| **Dijkstra** | 图搜索（盲目） | 是 | 即 $h(n)=0$ 的 A*，能处理变长边权 |
| **A\*** | 图搜索（启发式） | 是 | 核心启发式引擎，$f(n)=g(n)+h(n)$ |
| **加权 A\*** (W=2) | 图搜索（启发式） | 否（次优解） | $f(n)=g(n)+W \cdot h(n)$，速度最快 |
| **IDA\*** | 树搜索（启发式） | 是 | 用时间换空间，空间复杂度降至线性 $O(b \cdot d)$ |

---

## 支持的启发函数

| 启发函数 | 公式 | 可采纳性 | 说明 |
|----------|------|:---:|------|
| **零启发** | $h(n)=0$ | ✓ | 退化为 Dijkstra，用作基准 |
| **错位棋子数** | $h(n)=\sum$ 不在目标位置的棋子数 | ✓ | 弱启发，扩展节点数大 |
| **曼哈顿距离** | $h(n)=\sum\vert x_i-x_g\vert+\vert y_i-y_g\vert$ | ✓ | 经典启发，大幅压缩搜索空间 |
| **线性冲突** | $h(n)=h_{manhattan}+2\times\text{Conflicts}$ | ✓ | 最强启发，修正棋子互斥导致的低估 |

## 已实现的交互功能

### 单屏刷新菜单

所有主要菜单页面均采用单屏刷新方式显示，进入下一步后不会保留上一步内容。数码回放与迷宫回放也采用同一区域逐帧刷新，而非不断向终端追加输出，整体交互流程接近"终端界面"而非"脚本问答串行输出"。

### 分层返回机制

主菜单、问题配置、预设选择、配置确认、算法选择、启发函数选择、结果页等层级均支持返回。返回逻辑不是简单退回主菜单，而是尽量回到真正的上一步。输入过程中也支持通过 `q` 返回上一步。

### 数码问题交互

- 支持使用预设测试例（简单/中等/困难）
- 支持手动构造初始状态：先生成空棋盘，再通过坐标编辑逐格填写（格式：`行 列 值`）
- 支持 `done` 完成填写、`clear` 清空棋盘、`行 列 x` 清空单格
- 目标状态支持使用标准目标态或手动编辑构造

### 迷宫问题交互

- 支持预设 8×8 迷宫、手动编辑迷宫、随机生成迷宫
- 手动编辑格式：`行 列 值`（0=空地, 1=墙, 2+=权重）
- 随机生成支持设置尺寸、障碍率、最大权重和随机种子
- 起点/终点输入统一为成对坐标格式

### 结果页与回放功能

求解完成后展示：算法名称、启发函数名称、总耗时、扩展节点数、Open 表峰值、步数、总代价与动作序列。结果页支持回放求解过程，数码问题额外支持查看初始/目标状态。

## 预防错误处理

- **输入合法性检查**：菜单选项校验、整数/浮点数校验、成对坐标校验、边界越界校验
- **数码问题防错**：实时显示剩余可填数字、检测数字重复/缺失、可解性预判
- **迷宫问题防错**：校验起点/终点不落在墙上、通过内部 BFS 判定连通性
- **算法选择风险提示**：当迷宫尺寸超过 8×8 选择 IDA* 时给出显式警告
- **运行过程健壮性**：捕获 `EOFError` 和 `KeyboardInterrupt`，优雅退出

## 算法理论性能对照

| 算法 | 是否保证最优解 | 时间复杂度 | 空间复杂度 | 核心应用场景 |
|------|:---:|:---:|:---:|------|
| BFS | 是（仅边权相等） | $O(b^d)$ | $O(b^d)$ | 简单最短路基准 |
| Dijkstra | 是 | $O(b^d)$ | $O(b^d)$ | 无启发带权图寻路 |
| A*（错位棋子） | 是 | 极高 | $O(b^d)$ | 弱启发基准 |
| A*（曼哈顿） | 是 | 远小于 $O(b^d)$ | 远小于 $O(b^d)$ | 中型图最优寻路 |
| A*（线性冲突） | 是 | **极小** | **极小** | 严苛最优路径剪枝 |
| 加权 A* (W=2) | **否**（次优解） | 最快 | 最少 | 追求速度、允许误差 |
| IDA* | 是 | 大于 A* | **$O(b \cdot d)$** | 高维内存受限场景 |

## 创新点

### 1. 完整的多算法横向对比体系

引入 BFS 和 Dijkstra 作为盲目搜索基准，通过实验数据直观展示 A* 在启发式剪枝下的压倒性优势，并用错位棋子数衬托曼哈顿距离和线性冲突的启发质量提升。

### 2. 启发函数优化——线性冲突

指出曼哈顿距离"忽略棋子互斥"的缺陷，引入线性冲突启发函数：
$$h(n) = h_{manhattan}(n) + 2 \times \text{Conflicts}(n)$$

同一行或同一列中两个棋子互相阻挡目标位置时额外惩罚 +2 步，使预估更贴近真实代价。

### 3. A* 的时空权衡优化

- **加权 A\***：$f(n)=g(n)+2\times h(n)$，用次优解换取极致速度
- **IDA\***：抛弃大规模 Open/Closed 表，用树搜索 + 迭代加深，将空间复杂度从 $O(b^d)$ 降至线性的 $O(b \cdot d)$

### 4. 应用场景扩展

将搜索框架扩展至 15 数码问题（高维状态空间）和迷宫寻路问题（变长边权），并引入泥潭机制验证 BFS 在非均一代价图上的缺陷。

### 5. 工程解耦设计

通过 `Problem` 抽象基类和统一 `Node` 接口，实现核心算法与具体问题的完全解耦。引入 15 数码和迷宫时，`a_star` 等核心搜索函数一行代码都无需修改，体现面向对象设计的可扩展性精髓。
